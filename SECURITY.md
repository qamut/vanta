# Security

## Reporting a vulnerability

Please report security issues privately, either through GitHub's
[private vulnerability reporting](https://github.com/qamut/vanta/security/advisories/new)
or by email to **hi@notrix.com.br**. Do not open a public issue.

Include the VANTA version, your Windows version, the steps to reproduce and the impact you expect.
You will get an answer within a few days.

## Scope

- The VANTA app (`src/`, `src-tauri/`) and its installer (`installer/`).
- The browser extension and its Native Messaging bridge (`browser-extension/`, `src-tauri/src/bridge/`).
- How VANTA downloads and verifies yt-dlp and gallery-dl.

Only the latest release receives security fixes.
